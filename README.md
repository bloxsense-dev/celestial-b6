# Celestial — порт на Minecraft 26.2

Исходники клиента Celestial на базе MCP-Reborn, с ресурсами интерфейса и слоем совместимости старых модулей.

## Требования

- JDK 25; Gradle тоже должен запускаться на JDK 25.
- Gradle Wrapper включён в репозиторий.
- Интернет для первой загрузки зависимостей и ресурсов Minecraft.

## Сборка и запуск

Из корня проекта (PowerShell):

```powershell
.\gradlew.bat copyAssets
.\gradlew.bat compileJava
.\gradlew.bat runclient
```

Linux/macOS: используйте `bash ./gradlew` вместо `.\gradlew.bat`.

Исходники уже находятся в репозитории. Задача `setup` предназначена для получения исходников чистого Minecraft; для обычной сборки этого клиента она не нужна.

## Структура

- `src/main/java` — клиент, Minecraft и слой совместимости.
- `src/main/resources` — шрифты, текстуры и другие ресурсы.
- `gradle` — Gradle Wrapper.
- `build.gradle`, `settings.gradle`, `gradle.properties` — конфигурация сборки.
- `docs/MCP-Reborn.md`, `MCP-License` — исходная документация и условия MCP.

Папки `build`, `.gradle`, `run`, `runserver`, настройки IDE и диагностические файлы не включаются в Git. Миры, аккаунты и конфигурация запуска остаются локальными.

## Состояние порта

Порт находится в разработке. Исправлены основные мосты рендера и ввода, меню, экран смерти, HUD, Trails и NameTags. Не все старые модули и серверные режимы проверены.
